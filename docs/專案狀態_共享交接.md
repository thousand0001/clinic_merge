## 七、ID 格式（全專案統一規則）

```python
re.fullmatch(r"(?:[A-Z][1289]\d{8}|[A-Z][A-D]\d{8})", normalize_id(value))
```

- `[A-Z][12]\d{8}`：本國身分證
- `[A-Z][89]\d{8}`：新式外來人口統一證號（110 年後）
- `[A-Z][A-D]\d{8}`：舊式外來人口統一證號（110 年前）
- 禁止只用 `[A-Z][12]\d{8}` — 會誤殺外來人口 ID
