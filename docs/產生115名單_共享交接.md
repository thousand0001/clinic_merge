# 產生115名單：Codex / Claude Code 共享交接

最後更新：2026-06-16

## 主題定義

本主題名稱是「產生115名單」，主要目標是從選會員結果產生健保
MHB5 規格的 `FM.txt` 上傳檔。

這不是 `db_pipeline` 的 PostgreSQL 原始資料上傳。資料庫上傳規格另見
`docs/upload-pipeline-rules.md`，不要混入本主題。

## 主程式（目前使用）

```text
產生115年健保署上傳名單_0616.py
```

tkinter GUI，純 Excel 來源（不查資料庫）。

**功能：**

- 選會員來源 xlsx + 5 個醫事人員身分證號欄位（可貼上）
- GUI 按鈕 1：**輸出自選會員 B** — 讀醫生看 AG 欄（自選 E1），排除同時為 AF 欄（不選 E2）的會員，CASE_TYPE=`B`，輸出至 `自選會員/`
- GUI 按鈕 2：**輸出指定會員 A** — 讀醫生看 AQ 欄（115年指定會員），無 E1/E2 過濾，CASE_TYPE=`A`，輸出至 `指定會員/`
- 名單為空 → 終端機印訊息 + GUI 警告視窗
- 覆蓋前彈出確認對話框（預設 No）
- 輸出路徑：`Desktop/健保署115年上傳名單/{院所代碼}{院所名稱}/{自選會員|指定會員}/`
- 檔名：`{BRANCH}{院所代碼}{月份}{流水號:02d}FM.txt`
- CP950 編碼，定長 208 bytes/筆，CRLF 結尾，每份最多 9999 筆

**FM.txt 欄位規格（208 bytes/筆）：**

```
A(1) + PLAN_NO(2,"17") + BRANCH(1,"1") + HOSP_ID(10) + PID(10)
+ BIRTHDAY(8) + NAME(12) + SEX(1) + ADDR(120) + TEL(15)
+ PRSN_ID(10) + CASE_TYPE(1) + CASE_DATE(8) + CLOSE_DATE(8空白) + CLOSE_RSN(1空白)
```

**關鍵欄位索引（醫生看 sheet，0-based，資料從第 4 列起）：**

| 常數 | 索引 | 欄 | 說明 |
|---|---|---|---|
| IDX_PID | 0 | A | 身份證號碼 |
| IDX_NAME | 1 | B | 姓名 |
| IDX_BIRTH | 2 | C | 生日 |
| IDX_TEL | 4 | E | 電話 |
| IDX_MOBILE | 5 | F | 手機號碼 |
| IDX_115X | 31 | AF | 不選（E2） |
| IDX_SELF | 32 | AG | 自選會員（E1） |
| IDX_DESIGNATED | 42 | AQ | 115年指定會員 |

**關鍵欄位索引（會員總表 sheet，0-based）：**

| 常數 | 索引 | 欄 | 說明 |
|---|---|---|---|
| MASTER_IDX_PID | 4 | E | 身份證號碼 |
| MASTER_IDX_TEL | 8 | I | 電話 |
| MASTER_IDX_MOB | 9 | J | 手機號碼 |
| MASTER_IDX_ADDR | 57 | BF | 地址 |

**地址/電話優先順序：**

1. 醫生看 F 欄（手機）> E 欄（電話）
2. 無資料 → 查會員總表 J 欄 > I 欄（電話）；地址查 BF 欄
3. 仍無資料 → 採用診所地址/電話（從 `醫療群_衛福部資料.xlsx` 讀取）

**診所資料來源（`醫療群_衛福部資料.xlsx`，0-based，資料從第 3 列起）：**

- col 1：醫事機構代碼
- col 3：醫事機構名稱
- col 4：機構地址
- col 5：電話區域號碼（lstrip("0") 後補回 "0" 前綴）
- col 6：電話號碼

**已知陷阱：**

- `rstrip(".0")` 會截斷含連續 `0` 的院所代碼（如 `3531046600` → `35310466`）。
  正確做法：`_strip_float_suffix(s)` 用 `endswith(".0")` 判斷。
- 電話區域號碼儲存為整數時，`lstrip("0")` 後才組合，避免 `00222...` 雙零。
- MASTER_IDX_ADDR 是 57（BF 欄），不是 56（BE 欄）。

## 相關但不同的程式

### `115會員生成/產生115年指定名單.py`

- 輸出指定名單 **Excel**，不產生 FM.txt。
- 勿混用。

### `tools/export_115_designated_list.py`

- 官方 16 欄指定名單 Excel 匯出，也不產生 FM.txt。

### `tools/generate_fm_txt.py`

- 舊版 FM.txt 工具，會查 PostgreSQL。
- 目前改用 `產生115年健保署上傳名單_0616.py`（純 Excel，不需 DB）。

## 保護規則

1. 不修改官方樣板格式或覆蓋樣板。
2. 不覆蓋來源選會員 Excel。
3. `醫療群_衛福部資料.xlsx` 只讀，不可修改或覆蓋。
4. FM 輸出必須依官方命名規則。
5. Python 需相容 Python 3.9。
6. 修改任何 `.py` 前，依 `AGENTS.md` 先取得使用者同意並備份原檔。
7. 驗證只讀必要欄位，不掃描無關診所或大型輸出 workbook。
