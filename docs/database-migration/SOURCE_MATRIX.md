# 來源系統初始矩陣

此矩陣是第一版解析器規劃依據；實作時仍需逐診所來源覆蓋檢查。

| 系統 | 代表診所 | 常見格式 | 已知特殊規則 |
|---|---|---|---|
| SM／耀聖 | 本一 | `sm_*.xlsx`、一般 xlsx、月報 xlsx/xls | 同類 `sm_*` 欄位大致一致；部分診所檔名不含 `sm_` |
| 新耀聖 | 吉安 | xlsx | 照護名單具 AW:BJ 對應欄位；部分診所缺照護名單 |
| 展望 | 陳森豊 | xlsx、逐月費用 xlsx | 費用逐月；非雲端與雲端流程需分開驗證 |
| 醫聖 | 鈞安 | BIG5 固定寬度 TXT、xlsx | 次數／費用需依固定欄寬解析 |
| 調和 | 蘆洲大愛 | BIG5 CSV、xlsx | CSV 可能含非法控制字元；需先清理暫存副本 |
| 宏誠 | 德容等 | 費用明細 xlsx、次數 PDF | PDF 轉換必須保留來源追蹤與人工驗證 |
| 自行系統 | 書田 | xlsx | 月分頁名稱決定申報年月；日期欄是最後就診日 |

## 系統識別優先序

1. 使用者或命令列明確指定。
2. 診所設定檔中的醫事機構代碼。
3. 診所設定檔中的診所名稱。
4. 檔名、工作表名稱與表頭特徵。
5. 無法唯一判斷時停止並要求人工選擇。
