# 資料庫模式驗收清單

## 代表診所

第一輪建議使用：

| 系統 | 代表診所 | 用途 |
|---|---|---|
| SM／耀聖 | 本一 | 一般耀聖、照護名單、月費、P4P、篩檢 |
| 新耀聖 | 吉安 | 新耀聖完整 AW:BJ |
| 展望 | 陳森豊 | 非雲端展望、自選與不選 |
| 醫聖 | 鈞安 | TXT/BIG5 與完整 AW:BJ |
| 調和 | 蘆洲大愛 | CSV/BIG5 與前置清洗 |
| 自行系統 | 書田 | 大型資料量及月份分頁規則 |

後續再加入方鼎、宏誠、杏翔與其他特殊格式。

## 每批輸入驗收

- 有效來源檔案數。
- 成功解析檔案數。
- 略過檔案及原因。
- 無法解析列數及原因。
- 有效身分證筆數。
- 重複 ID 與採用規則。
- 來源檔、工作表、列號可追溯。

## 標準資料集驗收

- ID 已正規化。
- 日期支援西元與民國格式。
- 缺失值統一為空值。
- 次數與金額為數值型別。
- 114／115 年月歸類正確。
- 自選與不選來源旗標均保留。
- P4P 多筆資料不被覆蓋。

## Excel 輸出驗收

- 使用檔名日期最新模板。
- 樣板格式、合併儲存格、欄寬及列高保留。
- `會員總表` L/M/N/O 與來源加總一致。
- `醫生看` AW:BJ 與照護名單一致。
- 自選與不選重疊時列為不選。
- P4P、檢驗、篩檢及最後就診日均有來源覆蓋報告。
- 輸出檔名含時間戳。
- 輸出寫入獨立目錄。

## 資料庫驗收

- 單一批次使用 transaction。
- 失敗批次不更新 current。
- 相同檔案重跑不產生非預期重複資料。
- 可依 `batch_id` 查詢完整來源與輸出。
- 可回復上一個成功批次。
- 診所之間不可互相讀寫資料。
- 帳密不寫死在程式碼。

## 切換門檻

- 代表診所新舊輸出關鍵欄位完全一致。
- 所有差異均有書面原因及使用者確認。
- PostgreSQL 備份與還原演練成功。
- 權限與稽核紀錄完成。
- 平行運作期完成。
